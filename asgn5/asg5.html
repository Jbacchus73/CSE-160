Project Notes

  • Use WASD and the mouse to move around the island.
  • Press Tab to switch between walk mode and free-roam mode.
  • The scene uses OBJ/MTL models, textures, grass, trees, rocks, a dirt path, and a studio interior.
  • There is a day/night cycle, skybox, multiple lights, ambient audio, and music from the studio speakers.
  • I kept a lot of the extra details low-poly/simple so the scene still runs better.
