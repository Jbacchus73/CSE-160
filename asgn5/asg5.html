Notes for Grader

  • Tab switches between walk mode and free-roam mode.
  • Esc opens this settings menu.
  • The studio uses OBJ/MTL models, textured surfaces, lighting, music, and a day/night cycle.
  • Music and ambient audio can be turned on from this menu.

Things to Check

  • Audio only starts after pressing the buttons because browsers block autoplay.
  • In free-roam mode, click and drag with the mouse to rotate the camera.
  • Some assets may take a few seconds to load on GitHub Pages.
